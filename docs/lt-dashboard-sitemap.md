## 登入流程

1. 輸入帳號密碼 → 點「登入」
2. TOTP 驗證碼 modal 出現 → 填入 6 位數 OTP → 點「送出」
3. 導向 `#/management/all-management`

詳細技術陷阱（OTP input 特殊處理、TOTP 30 秒輪轉）請參考 `docs/dashboard-technical-notes.md`。

## 分類詳解

### 1. 儀表板（`#/dashboard`）

唯讀統計卡片：投注人數、投注金額、有效投注、玩家總贏、總金額、應收下線、應繳上級、交上線有效投注、貨量占比、個人盈虧。

---

### 2. 管理（`#/management/all-management`）

三個 Tab 共用左側代理樹導航。

#### 2a. 代理 Tab

| 欄位 | 序號、上級代理、帳號、暱稱、備註、額度 |
|------|------|
| **操作** | 設定、修改密碼、存入、提取、輸贏報表、新增下線代理 |

- 設定面板：玩家資料、廠商設定、退水、真人限紅、備註、餘額封頂限制
- 存入/提取彈窗：額度 input → 取消/送出

#### 2b. 會員 Tab

| 欄位 | 序號、上級代理、帳號、暱稱、備註、額度 |
|------|------|
| **操作** | 設定、存入、提取、新增會員（root level disabled） |

- 設定面板：1. 玩家資料 / 2. 廠商設定 / 3. 退水 / 4. 真人限紅 / 5. 備註 / *餘額封頂限制
- 排序：創建時間 / 帳號 × 升序 / 降序

#### 2c. 子帳號 Tab

| 欄位 | 序號、主帳號、帳號、暱稱、備註 |
|------|------|
| **操作** | 設定（編輯子帳號資料）、新增子帳號（root level disabled） |

#### 左側代理樹
- 首頁 → 下線代理列表（可點擊切換層級）
- 「下線代理管理」導航按鈕

## 關鍵操作路徑

### 會員充值（存入額度）
1. 導航到 `#/management/all-management`
2. 切換到「會員」Tab
3. 搜尋目標會員帳號
4. 點擊該會員的「存入」按鈕
5. 輸入存入額度金額
6. 點「送出」

### 會員額度驗證
- 會員列表直接顯示「額度」數值
- `#/report/quota-history` 可查詢額度變動歷史
